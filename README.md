## 先分清：美国"大带宽"服务器其实是两类产品

雨云的美国节点在洛杉矶，分了两个区，线路定位差距相当大：

- **洛杉矶一区**：走国际大带宽线路，联通 AS4837（CU4837）。特点是带宽峰值高、单价低，但国内访问延迟偏高，实测经常跑不满标称带宽。适合下载站、网盘、海外站点、备份、视频分发这类"吞吐量优先、延迟不敏感"的业务。
- **洛杉矶二区**：移动 CMI + 联通 CU9929（AS9929）双线优化，三网直连回程。带宽不如一区夸张，但国内能跑满，延迟明显更低，适合面向国内用户的网站和跨境业务。

在带宽之外，还有第二个岔路口：**大带宽限流量型** 和 **小带宽不限流量型**。同一套 CPU/内存配置，两种模式价格一样，区别只在带宽和流量策略。流量用完后不会断网，而是限速到 5Mbps，需要恢复高速可以买流量包（约 30 元/1TB）。另外每个月用不完的流量可以结转到下个月继续用。

有一点容易踩坑：限流量的套餐是**双向计费**——上行和下行都算进流量额度。如果你做的是下载站，下行流量会被快速吃掉，选型时要按双向来估算。

## 哪些场景适合买，哪些场景别碰

**适合**：下载站、网盘、海外站点、软件分发、视频与静态资源的中转、爬虫与数据采集、跨境业务的中间节点、异地备份。这类业务的核心指标是吞吐量和流量成本，延迟排后面。

**不太适合**：

- **面向国内用户的普通网站**——除非你选二区优化线路，一区的国内访问体验会让访客流失。
- **需要抗攻击的业务**——一区没有可选防御，带宽大不等于抗打。
- **高并发数据库或计算密集型任务**——带宽不是瓶颈，CPU 单核性能和内存才是，选一区就是花钱买错方向。
- **只是搭个人博客或小工具站**——20 元级别的轻量档或二区入门档完全够用，不需要大带宽。

## 常见问题

**美国大带宽服务器需要备案吗？**
海外节点不涉及国内域名备案环节，这也是很多人选美国节点的直接原因。

**带宽是独享还是共享？**
标称的是峰值带宽，实际能跑多少取决于线路拥塞情况。洛杉矶一区延迟偏高、国内方向经常跑不满，这是国际大带宽线路的普遍现象，不是雨云独有的问题。

**流量用完了会断网吗？**
不会，会被限速到 5Mbps。可以购买流量包恢复高速，约 30 元/1TB，未用完的流量支持结转到下个月。

**第三方实测数据参考**
公开测评里，二区节点三网平均延迟约 163ms（联通约 157ms），磁盘 I/O 在 870–1500MB/s 区间，实际下载速率约 5.5MB/s。这些数字来自第三方测评文章，不同时间、不同测试点会有波动，只作为量级参考。

**能不能随时升配？**
可以，支持按天补差价升级套餐、扩容云盘、加购独立 IP，也可以在区域之间迁移。
